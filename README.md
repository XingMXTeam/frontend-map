# Frontend Map

> A personal frontend knowledge archive covering JavaScript, TypeScript, Vue, and broader frontend engineering topics.

This repository is a historical knowledge base from my frontend engineering years. It is not positioned as an active product repository. Its value is in documenting long-term learning, notes, and mental models around frontend development.

## Why keep this repository

Frontend knowledge is broad and fragmented. This repository was created to collect foundational and advanced topics into a more structured map.

> Rome was not built in a day. Frontend expertise is also accumulated through many small, repeated passes.
